## 2. Role & Access Control Architecture
1. **Superadmin Authority:**
   - Strictly reserved for the Firebase database administrator email (`davidrobertson.info@gmail.com` / `support@aifoundation.net.au`).
   - Custom claims: `{ role: "superadmin", tier: "agency", isSuperAdmin: true, admin: true, superadmin: true }`.
2. **Supporters (Default for All Other Users):**
   - Everyone else starts at supporter level with default claims: `{ role: "supporter", tier: "supporter", isSuperAdmin: false, admin: false }`.
   - On sign-in, `/api/me` ensures non-admin accounts are normalized to supporter level.
3. **UI Protection Gate:**
   - The TopNav Account Menu shows a "Super Admin" badge for database admins and a "Supporter" badge for standard users.
   - The "Super Admin Panel" action is rendered strictly for the database admin. Standard users only see "Message Super Admin".
4. **API Route Protection:**
   - `/api/admin/config` (GET, PUT, POST) and `/api/admin/messages` (GET, PATCH) enforce `requireRole: "superadmin"` and reject unauthorized users with 403 Forbidden.
