## 2. Role & Access Control Architecture
1. **Superadmin Authority:**
   - Strictly reserved for the Firebase database administrator email (`davidrobertson.info@gmail.com` / `support@aifoundation.net.au`).
   - Custom claims: `{ role: "superadmin", tier: "agency", isSuperAdmin: true, admin: true, superadmin: true }`.
2. **Supporters (Default for All Other Users):**
   - Everyone else starts at supporter level with default claims: `{ role: "supporter", tier: "supporter", isSuperAdmin: false, admin: false }`.
   - On sign-in, `/api/me` ensures non-admin accounts are normalized to supporter level.
3. **Interactive RBAC Matrix & Responsive Superadmin Navbar:**
   - SuperAdmin navbar rebuilt into a clean, responsive, fluid grid (4x2 on tablet/desktop, 2x4 on mobile) with **zero scrollbars**.
   - Symmetrically displays all 8 tabs clearly:
     1. Currency Controls
     2. Service Pricing
     3. Token Packs (CRUD)
     4. Redistributive Ledger
     5. User Messages (with unread count)
     6. RBAC Matrix & Roles
     7. Help & FAQs (with total count)
     8. Developer Diagnostics
   - Full 2D Permission-Role matrix tab with locked Superadmin capabilities and toggleable permissions for all other roles.
   - User Accounts Table allows Superadmin to inspect all users and assign roles via Firebase custom claims with instant update.
4. **Navbar Menu Order, Hover Popups & Mobile Tab Bar:**
   - Desktop & Mobile Navigation: "My Brands" is first, followed by "Radar Feed", then "Wallet".
   - Rich hover popup tooltips on desktop explaining both My Brands and Radar Feed.
   - On Android & iPhone mobile bottom bar: "My Brands" is first with an interactive `?` trigger that expands a collapsible explanation card above the bottom bar.
   - Informs users that they can create as many Brands as they want, then choose which one to research & remix.
   - Includes collapsible details guide at the top of the My Brands page.
5. **Knowledge Base FAQs Management:**
   - Super Admin Panel includes dedicated "Help & FAQs" tab.
   - Superadmin can add, edit, reorder, toggle, and delete FAQs (with confirmation).
   - Seeded with comprehensive FAQs explaining "What is My Brands?", "What is Radar Feed?", and "How do Token Deductions Work?".
6. **UI Protection Gate:**
   - The TopNav Account Menu shows a "Super Admin" badge for database admins and a "Supporter" badge for standard users.
   - The "Super Admin Panel" action is rendered strictly for the database admin. Standard users only see "Message Super Admin".
7. **API Route Protection:**
   - `/api/admin/config` (GET, PUT, POST), `/api/admin/messages` (GET, PATCH), `/api/admin/rbac` (GET, PUT), and `/api/admin/faqs` (GET, POST, PUT, DELETE) enforce `requireRole: "superadmin"`.
