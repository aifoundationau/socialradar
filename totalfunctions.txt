This section details the functions powering AdRadarHQ, categorised by subsystem,

### 1. Token Ledger & Transaction Gatekeeper (src/lib/token-ledger.ts)

- **`withTokenGate()`**: Atomic gatekeeper executing transactional deductions before performing paid operations (Radar Search, AI Remix, Customize Briefs, Brand Clones). Verifies user authentication, checks custom claim role exemptions (Super Admin = 0 tokens), ensures non-negative balance, records immutable ledger tx in token_transactions, and executes compensating failure refunds (<txId>_refund) atomically if downstream operations fail.
- **`creditTokens()`**: Atomically adds integer tokens to users/{uid}.tokenBalance via Firestore transaction. Sets deterministic txId, enforces whole numbers (Math.round), logs transaction with audit referenceId and txType (TOPUP, GIFT, REFUND), and handles Stripe checkout fulfillments.
- **`getUserBalance()`**: Fetches live integer token balance from users/{uid}. Enforces strict non-negative guarantee (Math.max(0, balance)) and returns zero for unauthenticated or non-existent profiles.
- **`refundTokens()`**: Compensating transaction that refunds previously debited tokens back to users/{uid} when an upstream API provider (SearchApi.io, Gemini) encounters a 502/timeout, marking the original txId as refunded.
- **`getLedgerHistory()`**: Retrieves owner-scoped transaction history from token_transactions collection with pagination, order sorting (createdAt desc), and human-readable metadata enrichment.
- **`resetUserTokensToZero()`**: Administrative ledger action that resets a user's token balance to 0, logging an ADMIN_RESET transaction with mandatory audit note and admin email attribution.

### 2. SuperAdmin Governance & Redistributive Ledger (src/lib/admin.ts)

- **`getSystemConfig()`**: Retrieves global platform configuration from system_config/global with fallback defaults: currency toggles, base token price, service pricing matrix, subscription 1K status, and equity partners roster.
- **`updateSystemConfig()`**: Mutates platform settings with Zod schema validation (SystemConfigSchema.strict()) and audit trail recording (updatedAt, updatedBy).
- **`getRedistributiveLedger()`**: Aggregates total Stripe purchases exclusively from stripe_purchases collection. Sums totalTokens (integers only), totalGrossAudCents, and totalGrossUsdCents. Computes equity partner ownership and treasury retained pool. Super Admin gifted tokens are strictly excluded.
- **`recordStripePurchase()`**: Writes an immutable Stripe purchase record into stripe_purchases collection, triggered exclusively by verified Stripe webhooks.
- **`resetRedistributiveLedger()`**: Archives all records from stripe_purchases into archived_stripe_purchases with audit metadata and clears stripe_purchases, safely resetting Total Tokens and Revenue to 0.
- **`resetPartnerTokens()`**: Resets an individual equity partner's claimed tokens and revenue balance to 0, updating partner audit timestamps.
- **`giftTokensToUser()`**: Adds integer tokens at no charge ($0) to a user's wallet via creditTokens with txType: GIFT, bypassing Stripe and excluding from Redistributive Ledger.
- **`deductTokensFromUser()`**: Administrative action deducting integer tokens from a user wallet with hard non-negative enforcement (balance never drops below 0).
- **`getMasterOrderLedger()`**: Combines token_transactions (all searches, remixes, gifts, top-ups) and stripe_purchases, enriched with customer email and refund status, for Super Admin audit.
- **`refundOrder()`**: Two-step administrative order refund restoring exact deducted tokens back to customer balance and marking order refunded.
- **`getStripePurchases()`**: Fetches recent Stripe purchase records with limit and descending timestamp sort.

PART II: COMPLETE ADMIN CONTROLS DIRECTORY & HOW THEY WORK (77 TOTAL)

AdRadarHQ features 77 discrete administrative controls distributed across 11
governance suites in the SuperAdmin Control Panel (SuperAdminModal.tsx) and Main Admin:

SUITE 1: CURRENCY & FOREIGN EXCHANGE CONTROLS (5 Controls)
1. Token System Master Toggle (isTokenSystemEnabled):
   - How it works: Enables or disables platform-wide token gate enforcement. When enabled, actions require integer token debits; when disabled, actions run at 0 cost.
2. Australian Dollar Invoicing Toggle (isAudEnabled):
   - How it works: Controls AUD checkout availability and invoice generation. Australian entity legal default.
3. Indicative USD Toggle (isUsdEnabled):
   - How it works: Displays/hides foreign exchange conversion estimates alongside AUD prices for international visitors.
4. Base Token Price in AUD (centsPerToken):
   - How it works: Sets base value of 1 token in AUD cents (default: 100 cents = $1.00 AUD). Updates all token pack formulas.
5. Sync ECB Foreign Exchange Rates (syncEcbRates):
   - How it works: One-click sync fetching official ECB daily rates to calibrate indicative USD conversion.

SUITE 2: SERVICE & PRODUCT PRICING CONTROLS (10 Controls)
6. Base Radar Search Cost (searchStandard):
   - How it works: Sets token deduction for standard Meta, TikTok, or Google ad library search (default: 1 Token).
